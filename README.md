# Employee Portal

Rose-themed portal with employee cards.

## Run
1. Extract the ZIP and open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address printed in the terminal.

## Pages
- Home (`/`): loads users from https://jsonplaceholder.typicode.com/users and displays ID, name, and email.
- Employee Form (`/employee-form`): Name, Designation, Location, and Salary fields.

This is a basic front-end assignment. The form validates required fields and displays a demo success message; it does not save to a database.
